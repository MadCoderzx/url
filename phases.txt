Phase 3: URL Shortening API

Goal: Create short URLs without auth.

Routes:

POST /api/urls
GET /api/urls?clientId=<client_id>
DELETE /api/urls/:id
Rules:

POST /api/urls receives:

originalUrl
clientId
Backend validates:

valid URL
non-empty clientId
Backend generates unique shortCode.

GET /api/urls?clientId= returns only URLs for that browser/device.

DELETE /api/urls/:id should require clientId in query/body/header so one client cannot delete another client’s URL.

Success criteria:

A client can create, list, and delete its own URLs.

Commit:

git add .
git commit -m "Phase 3: add URL management API"
