# URL Shortener with CI/CD Pipeline

## Project Overview

Build a URL shortening service similar to Bitly that converts long URLs into short links and redirects users to the original destination.

The primary goal is to demonstrate a complete CI/CD workflow using GitHub Actions.

---

## Tech Stack

Frontend:

* React

Backend:

* Node.js
* Express.js

Database:

* PostgreSQL

CI/CD:

* GitHub Actions

Containerization:

* Docker

---

## Core Features

### URL Shortening

Input:
Long URL

Output:
Short URL

Example:

https://example.com/very/long/url

↓

https://short.ly/abc123

---

### URL Redirection

Visiting short URL should redirect to original URL.

---

### Dashboard

Display:

## CI/CD Requirements

Workflow 1:
Continuous Integration

On every push:

* Install dependencies
* Run linting
* Run tests
* Build application

Workflow 2:
Continuous Deployment

On successful build:

* Build Docker image
* Push image to container registry
* Deploy application
